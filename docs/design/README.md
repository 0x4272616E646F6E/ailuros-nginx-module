# Design notes

These notes record why the module is built the way it is: the constraints, the
decisions and the alternatives that were turned down. The main
[README](../../README.md) says how to install and configure it; the code says
what it does. Each note ends with a dated history of changes to the design.

- [module.md](module.md): the directives, where the check runs, how decision-waf's
  answers are applied, delivery into NGINX Gateway Fabric by ConfigMap,
